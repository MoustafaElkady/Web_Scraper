# YallaKora
A Python program that scrapes match results and schedules from the "YallaKora" website based on a date selected by the user, with the ability to display the results in a graphical user interface (GUI) and save them to a CSV file.

# Features

Graphical User Interface (GUI): User-friendly interface built using the tkinter library.  
Date Selection: Ability to select any specific date to fetch match details.  
Data Export: Option to save the extracted results into a .csv file for use in Excel.  
Error Handling: Includes alerts for scenarios such as no matches found or connection issues.  

# Requirements
The program runs on Python 3. You must install the following libraries using the command:

requests 
beautifulsoup4 
tkcalendar 
lxml

# How to UseRun the file named 4.py.  

A splash screen will appear, followed by the main window.  
Select the desired date from the calendar picker.  
Click on "Start Fetching Data" ("بدء جلب البيانات").  
After the results are displayed, you can save them to a CSV file by clicking "Save Results as CSV" ("حفظ النتائج كـ CSV").
