# YallaKora 
برنامج مكتوب بلغة بايثون يقوم بجلب نتائج ومواعيد المباريات من موقع "يلا كورة" بناءً على التاريخ الذي يختاره المستخدم، مع إمكانية عرض النتائج داخل واجهة رسومية وحفظها في ملف CSV.

# المميزات
واجهة رسومية (GUI): سهلة الاستخدام باستخدام مكتبة tkinter.

اختيار التاريخ: إمكانية تحديد أي تاريخ لجلب المباريات الخاصة به.

تصدير البيانات: إمكانية حفظ النتائج المستخرجة في ملف .csv لفتحها عبر Excel.

معالجة الأخطاء: يتضمن تنبيهات في حال عدم وجود مباريات أو مشاكل في الاتصال.

# المتطلبات (Requirements)

يعمل البرنامج باستخدام بايثون 3. يجب تثبيت المكتبات التالية عبر الأمر:


requests 
beautifulsoup4 
tkcalendar 
lxml
# طريقة الاستخدام

قم بتشغيل ملف 4.py.

ستظهر شاشة ترحيبية ثم النافذة الرئيسية.

اختر التاريخ المطلوب من أداة اختيار التقويم.

اضغط على "بدء جلب البيانات".

بعد ظهور النتائج، يمكنك حفظها في ملف CSV بالضغط على "حفظ النتائج كـ CSV".
